# مزيكاتي

مشغل أغاني وفيديوهات من ملفات التليفون. موقع ثابت بدون سيرفر، بيشتغل على GitHub Pages.

## المميزات
- أغاني وفيديو في تبويبين مع بحث
- شاشة تشغيل كاملة: اسحب لفوق للتالي ولتحت للسابق
- عشوائي وتكرار وتحكم في السرعة وأزرار شاشة القفل
- وضع ليلي ونهاري وتلقائي
- صورة خلفية من اختيارك مع تحكم في التعتيم
- إعدادات للشكل: لون التمييز، شكل المكتبة، شكل المشغّل، الزوايا
- بيتثبت على التليفون كتطبيق (PWA) وبيفتح من غير نت بعد أول مرة

## النشر على GitHub Pages
1. اعمل Repository جديد على GitHub (مثلا `mazzikati`).
2. ارفع كل ملفات المجلد ده كما هي (مع الفولدرات `css` و`js`).
3. من **Settings ← Pages** اختار **Deploy from a branch** ثم الفرع `main` والمجلد `/ (root)` واضغط Save.
4. بعد دقيقة هيظهر الرابط: `https://اسم-المستخدم.github.io/mazzikati/`
5. افتح الرابط من الكروم في التليفون واختار **Add to Home screen** علشان يتثبت.

## التجربة على الجهاز
```
python -m http.server 8000
```
وافتح `http://localhost:8000`.

## هيكل الملفات
```
index.html              الصفحة
css/style.css           التصميم (الألوان في أول الملف)
js/app.js               المشغّل والإعدادات
sw.js                   العمل بدون نت
manifest.webmanifest    بيانات التثبيت كتطبيق
icon-192.png / icon-512.png   أيقونة التطبيق (الصورة اللي اخترتها)
```

## ملاحظات
- الملفات بتتشغل من التليفون مباشرة ومش بتترفع في أي مكان.
- قائمة الأغاني بتتمسح لما تقفل الصفحة لأن المتصفح مش بيحتفظ بالوصول للملفات. الإعدادات وصورة الخلفية بتتحفظ.
